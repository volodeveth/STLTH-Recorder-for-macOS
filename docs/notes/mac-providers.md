## Жорсткі вимоги до сервісу (без цього — мимо)

1. Apple Silicon (M1/M2/M4) **bare metal** — НЕ Intel, НЕ macOS-VPS/віртуалка
   (у VM проблеми з Apple ID для Xcode + віртуальний аудіостек).
2. Виділена машина (dedicated), не shared-акаунт.
3. Повні адмін/root-права (ставимо Xcode, Zoom, Chrome, BlackHole; клацаємо TCC).
4. macOS ≥ 14.4 (ідеал 15 або 26) або можливість оновити самому.
5. Доступ до GUI-сесії: VNC / remote desktop / KVM, не тільки SSH.
6. Оплата з України: міжнародна картка (Stripe), PayPal або крипта.

Бажано: погодинний/подобовий білінг (орієнтир ≤$5/день або ≤$100/міс), провіжн за
хвилини, RAM 8+ ГБ, SSD 100+ ГБ, датацентр у Європі, reboot/Recovery з панелі.

## Червоні прапорці

Intel/VMware/virtualized macOS; "managed, no admin"; setup fee > місячної плати;
dedicated M1 дешевше ~$50/міс (= прихований shared або VM).

## Рамка рішення

Різниця між найдешевшим ($24/тиж) і надійним ($76–99/міс) — ~$50–70. Якщо дешеві
шляхи не злітають за один вечір — брати OakHost/Macly і писати код. Найдорожчий
ресурс — дні розробки, не долари.
